# ケース02-可視性

本資料は K7（配置）× K8（可視性）× O1/O4 の正典である。
担う範囲: 基底/中間/末端/companion の可視性行列・asEnumish 返り値型 3 段規則・
IR-only アクセサ壁 3 形・E-2 生成側・実効可視性・when else 要否の位置依存（同一 module 面）。
規則 3（ENUMIZE_KIND_TYPE_NOT_DENOTABLE）の発火と言語委譲（可視性スコープ違反・EXPOSED_SUPER_CLASS）はケース04、
跨 module / MPP の外部観測面（E-2 消費側・else 要否の跨 module 面）はケース05、可視性編集（#7-c）の IC・決定性はケース06 が正典である。
