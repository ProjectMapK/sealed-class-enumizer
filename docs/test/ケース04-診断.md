# ケース04 診断

本資料は全診断（error 14・warning 1）の発火と near-miss、および言語エラーへの委譲境界（O2/O6）の正典である。  
跨 module・MPP での診断発火も本資料が正典とする（フィクスチャ diag-fail / diag-ok / diag-cross / diag-mpp / MPP sweep 系）。  
IC での発火・解除トグルはケース06、IR-only アクセサ等の可視性 box 観測はケース02、生成 API の実行時挙動はケース01 が正典。  
発火ケースは buildAndFail の file:line 照合、near-miss は成功ビルド（または当該断片不在）の照合で観測する。  
診断 ID の ENUMIZE_ 接頭辞は省略する（NS/MF/NESTED/AK/IL/KTD/CLC/LC/MMC/MSM/RNC/ES/MIOH・ON_EXPECT/ON_ACTUAL）。
