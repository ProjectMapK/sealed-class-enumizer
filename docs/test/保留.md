# 保留

本資料は駆動機構が無く検証不能な領域の台帳の正典である。
担う範囲は次元モデルの未駆動残余（K12〜K14 の環境・動態面）と将来拡張の拡張時検証であり、
本文ケース資料（API/VIS/ORD/DIA/XMP/BLD）には保留を置かない。
各領域は解除条件の成立時に該当ケース資料へ展開して本資料から除く。
検証対象外と判断した領域は欠番とし、判断内容を 1 行で残す（番号は繰り上げない）。
既知の制限ゲート（実挙動固定+仕様側 @Disabled）の台帳も本資料が持つ（§2）。

## 2. 既知の制限ゲート

GATE-01: 生成 Enumish を型引数に持つ typealias を @Enumize 基底 supertype の頭に使うと、エイリアスが先に解決されない配置で言語側バックエンド ICE となる（FE 診断なし・プラグイン対処余地なし・概要.md §7 既知制限）。  
実挙動は TypealiasGateTest（sweep-typealias-samefile-head）が回帰ゲートとして固定し、仕様どおりの成功アサートは @Disabled で保持・言語側解消でケース資料の通常ケースへ移行する。

GATE-02: @Enumize を typealias または import 別名の表記で付与すると、supertype 解決フェーズの候補判定が未解決のアノテーション型参照に触れて FileAnalysisException（Expected FirResolvedTypeRef）の ICE となる（FE 診断なし・FQN 表記と通常 import は生成へ到達する）。  
実挙動は ProbeGateTest#annotationNotationBehaviorIsPinned（probe-annotation-alias）が回帰ゲートとして固定し、候補判定側の解消時に DIA-67 の通常ケースへ移行する。

GATE-03: 階層外クラスの final 具象 label を継承する末端はコンパイルが黙って通り、生成 override が final メンバーを踏むため実行時のクラスロードで IncompatibleClassChangeError となる（FE 診断なし）。  
実挙動は ProbeGateTest#finalInheritedMemberBehaviorIsPinned（probe-final-member）が回帰ゲートとして固定し、検査拡張または生成スキップの導入時に DIA-70 の通常ケースへ移行する。
